# CAD File Index (English)

The CAD files in the repository root keep their original Chinese filenames (renaming them would break links). This index maps each one to an English description.

> Descriptions are translated from the filenames. The README does not describe these files, so check the models before relying on them.

## `CAD/`

| Original filename | English name | Notes |
|---|---|---|
| `CAD/打印头6.11修正.zip` | Print head, v6.11 (corrected) | Zip containing one STEP file of the print head. Per the README, there are printed and CNC versions of the print head; see the BOM. |
| `CAD/热端停靠坞6.11改.STEP` | Hotend dock, v6.11 (revised) | STEP model of the dock that stores the parked hotends. |

## `拼版（5.5和5.1版本）/` — Print-plate layouts (v5.5 and v5.1)

"拼版" means parts panelized (arranged) on one plate for printing. The folder name translates to "Plate layouts (v5.5 and v5.1 versions)".

| Original filename | English name |
|---|---|
| `5.1摆臂PB2_螺纹可识别.step` | v5.1 swing arm, plate PB2 (threads recognizable) |
| `5.1盖板PB1.step` | v5.1 cover plate, plate PB1 |
| `5.1背板2.5mm皮带槽.step` | v5.1 back plate, 2.5 mm belt groove |
